ЭРА. Приватный серверный пакет для PHP 8.3

Распакуйте архив в <корень аккаунта>/era-private, рядом с каталогом www.
Каталог era-private должен находиться за пределами всех публичных корней.
Не загружайте архив или его содержимое в www/era-cycle.ru.

Скопируйте config.example.json в config.json в этом приватном каталоге.
Заполните действительный абсолютный путь web_root, права config.json — 0600,
права era-private и каталога state — 0700. PHP домена и CRON должны работать от
пользователя аккаунта. SMTP использует TLS на порту 465 и аутентификацию noreply@era-cycle.ru.

Оставьте requests_enabled выключенным до согласования согласия и политики.
Смотрите ERA_REG_RU_DEPLOY_STEPS.md из комплекта размещения. В архиве есть
фиксированная версия PHPMailer, её лицензия и контрольная сумма источника.
CRON запускается только PHP CLI. Его файл — cron/update_cbr.php.
