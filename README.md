# ЭРА — сайт проекта

Версия 0.14.1: компактный вход в общий каталог с крупным вариантом экспозиции узлов, тонкой золотой каёмкой при наведении и вступлением «Оборудование под вашу технологию». Изображения заполняют окна до краёв; оборудование видно целиком. Карточки высотой 536–560 px на настольном экране включают изображение, название и переход. Статический многостраничный сайт без внешних npm-зависимостей.

## Запуск и сборка

Требуется Node.js 22 или новее. Установка npm-пакетов не нужна.

```sh
cd /workspace/Website_ERA
npm run dev
```

Сервер слушает порт 3000. Можно указать другой: `PORT=3001 npm run dev`. При восстановлении облачной среды процесс запускают заново. Используйте существующий checkout; отдельный Git worktree не требуется.

```sh
npm run build
npm test
```

Результат сборки — `dist/`, 30 HTML-страниц, изображения, CSS/JS и документы. Сервер разработки выполняет сборку при запуске. После правок нужно снова выполнить сборку и обновить браузер; автоматического обновления пока нет. Не запускайте одновременные сборки: они записывают один каталог.

## GitHub Pages и версии

Публикация настроена через `.github/workflows/pages.yml` после обновления ветки `main`. В GitHub **Settings → Pages → Source** должен быть выбран **GitHub Actions**. Ручной запуск доступен через **Actions → Test and deploy ERA preview → Run workflow**.

Адрес проекта: https://eduyard13.github.io/Website_ERA/.

```sh
BASE_PATH=/Website_ERA npm test
BASE_PATH=/Website_ERA npm run build
```

Для проверки той же структуры локально:

```sh
BASE_PATH=/Website_ERA PORT=3003 npm run dev
```

BASE_PATH применяется к ссылкам, изображениям, srcset, PDF, адресам в data-атрибутах и странице 404. На статическом хостинге нужны поддержка index.html в каталогах и выдача 404.html с правильным статусом. Для размещения в корне или на своём домене BASE_PATH оставляют пустым и меняют соответствующее значение в workflow.

Согласованные этапы сохранены тегами v0.1.0–v0.14.1. История описана в CHANGELOG.md. Откат выполняйте отдельным коммитом, сохраняя последующую историю. Версия CSS/JS берётся из package.json для обновления кэшированных ресурсов.

## Источники и точность

Сайт основан на брифе 2.0, презентации ЭРА, 12 технических описаниях и 12 брошюрах владельца. Для каталога используются только технические иллюстрации из PDF, без номеров; фотографии размещаются отдельно на страницах узлов и в галерее. Из PDF извлечены оригинальные растровые и векторные иллюстрации. Для части интерактивных видов ImageGen удалил встроенные в растр выноски и фон; происхождение и обработка указаны в docs/interactive-scheme.md. Обозначения и объяснения сверены с техническими описаниями. Роторный распушитель показывает три функциональные стадии очистки.

Из 11 архивов заказчика добавлено 65 обработанных фотографий. Веб-копии WebP имеют до 1920 пикселей по большей стороне, миниатюры — до 800; увеличения исходного разрешения нет. Миниатюры загружаются отложенно, полный файл открывается в просмотрщике. Обложки каталога заменены схемами из технических описаний; главные фото страниц узлов выбираются независимо. Номера и подписи исходников сохранены в реестре. Общий размер новых изображений с миниатюрами — около 20,3 МБ; галерея не скачивает все полные изображения при открытии.

Для комплекса очистки стоков архив фотографий пока не предоставлен: используются схемы и кадры из PDF. Архив «Предварительный измельчитель» сопоставлен с предварительным распушителем по конструкции и фотографиям из его КП; пре-шредер загружен отдельно.

24 исходных PDF сохранены побайтно: 12 документов оборудования в public/documents/technical/ и 12 брошюр в public/documents/brochures/. КП опубликованы как «Техническое описание», документы бункера и рамы — как «Паспорт и техническое описание». Имена загрузок: «ЭРА — Брошюра — …pdf» и «ЭРА — Техническое описание — …pdf». Ссылки и download-имена берутся из одного реестра; SHA-256, оригинальное имя, размер и число страниц сохранены. Суммарно 108,5 МБ PDF загружаются только при открытии или скачивании. Папки библиотеки поддерживают поиск, тип документа, выбор узла и восстановление фильтра из URL.

По указанию владельца все 12 узлов показывают расчётную потребляемую мощность: установленная × 0,70, округление до одного знака после запятой. Расчёт вынесен в content/power.mjs и применяется к таблицам, кратким параметрам и акцентным показателям; исходные PDF не меняются. Расчётные значения подписаны отдельно от установленной мощности. Объёмная подача сепаратора в м³/ч, ёмкость бункера в м³ и массовая подача полимеров не смешиваются. Целевые показатели влажности сопровождаются условиями подтверждения на согласованном сырье.

Капсулятор по последнему КП описан как отжимной пресс, не как гранулятор. Компоновки из презентации не назначены автоматически конкретным комплектациям линий. Две сепарационные и одна моечная запись включены по умолчанию; третья сепарационная управляется данными и переключателем. Их состав и параметры ещё требуют спецификаций.

В медиатеке различаются фото, визуализации, схемы и кадры из видео. Кадр из PDF не считается загруженным видеороликом. Тип изображений из КП центрифуги и флотатора сохранён по оговоркам источников; новые изображения из архивов классифицированы как фотографии. Полная видеопрезентация предварительного измельчителя получена из GitHub Releases и сохранена без изменений: 104,52 секунды, 1920×1080, H.264/AAC, 47 412 133 байта. Постер извлечён на 10-й секунде. Видео не загружается при обычном открытии страницы; источник подключается после нажатия «Смотреть видео». Видеопрезентация баллистического сепаратора добавлена целиком: 2502 кадра, 1920×1080, 25 кадров/с; веб-копия 48 МБ с исходной аудиодорожкой, постер на 36-й секунде. У остальных узлов видеоблок появляется при наличии записи ready:true.

Подробные редакционные решения: `docs/presentation-notes.md`, `docs/equipment-sources.md`, `docs/photo-sources.md`, `docs/video-notes.md` и `docs/cbr-rates.md`, интерактивная схема — `docs/interactive-scheme.md`. Сохранённый бриф — `docs/ERA_Website_Brief_v2.md`.

## Проверки

`npm test` проверяет внутренние маршруты и ресурсы всех страниц, srcset и базовый путь, параметры, различия единиц, 24 PDF и их контрольные суммы, активное состояние навигации, соответствие фотографий узлам, миниатюры, схемы каталога и 130 интерактивных обозначений, единый расчёт мощности и десятичное округление, контрольные суммы MP4, сохранение кадров и длительности веб-копии, порядок метаданных для быстрого начала воспроизведения, панели на всех страницах, даты и номиналы ЦБ. Workflow выполняет проверки для корня и /Website_ERA/.

Дополнительные браузерные проверки требуют Python, Playwright и Chromium:

```sh
python3 test/refinements.browser.py
python3 test/navigation.browser.py
python3 test/presentation.browser.py
python3 test/equipment.browser.py
python3 test/media.browser.py
python3 test/equipment-video.browser.py
python3 test/fx.browser.py
python3 test/diagram.browser.py
python3 test/all-diagrams.browser.py
python3 test/documents.browser.py
```

Презентационный сценарий по умолчанию ожидает сервер на порту 3002, оборудования — на 3003, галереи — на 3004, реального видео — на 3006, курсов валют и интерактивной схемы — на 3008; все с BASE_PATH=/Website_ERA. Сценарии всех схем и документов ожидают сервер на 3009. Адрес и каталог скриншотов переопределяются через ERA_PREVIEW_URL и ERA_SCREENSHOT_DIR. Браузерные сценарии не входят в npm-зависимости и не запускаются в GitHub Actions.

Видеоплеер описан в `docs/video-notes.md`. Команда `python3 test/video.browser.py` дополнительно требует FFmpeg, создаёт изолированный синтетический ролик и проверяет воспроизведение, перемотку, полноэкранный режим, остановку и ошибки. Тест не публикует ролик и не заменяет проверку исходного видео заказчика. Команда `python3 test/equipment-video.browser.py` отдельно воспроизводит настоящий ролик с сервера: проверяет длительность, разрешение, декодированные кадры, перемотку и появление в галерее.

## Автоматические курсы ЦБ РФ

USD, EUR и CNY показаны в общем подвале с двумя знаками после запятой: рубли за одну единицу валюты. Дата видна сразу; «Источник и актуальность» раскрывает статус, дату действия и ссылку на ЦБ РФ в потоке документа. В шапке валютного блока нет. Расписание GitHub Actions ежечасно получает XML ЦБ на текущий день по Москве и публикует проверенные JSON/XML в отдельной ветке данных. Открытая страница проверяет JSON каждые 15 минут, при возвращении к вкладке и восстановлении сети. В выходной дата действия ЦБ может предшествовать дню запроса — обе даты показаны корректно.

Последний корректный снимок сохраняется в браузере. Старые и сохранённые данные имеют свою дату и подпись; при отсутствии данных показываются прочерки. Подробности и проверки — в `docs/cbr-rates.md`. `python3 test/fx.browser.py` проверяет реальную выгрузку и сценарии отказов, включая автоматический опрос и кэш.
