# Навигация «3 + 2» — 0.35.4

Задание: [ERA_CODEX_NAVIGATION_RESTRUCTURE_3PLUS2_v0352.md](ERA_CODEX_NAVIGATION_RESTRUCTURE_3PLUS2_v0352.md). Реализация основана на опубликованной версии 0.35.3. Прямое поручение владельца в текущем сообщении — сразу обновить сайт, опубликовать и дать ссылку, без скриншотов — заменяет ограничения вложенного файла на публикацию и его запрос скриншотов.

## Изменения

- `content/navigation.mjs`: верхние ссылки «О проекте → Технология → Оборудование → Экономика → КАИР», пять общих групп меню и футера. Новости и блог скрыты только из навигации, их страницы доступны по прежним адресам.
- `scripts/navigation.mjs`: семантические группы 01–05, три основных и две вспомогательных; одно нижнее действие «Обсудить проект» ведёт к существующей форме. Для КАИР добавлена поясняющая подсказка. Точные и родительские активные состояния сохраняются.
- `public/navigation.css`: широкое меню до 1120 px; от 1200 px — три колонки сверху и две снизу, 768–1199 px — две колонки в порядке 01–05, до 767 px — одна. Шапка с закрытием остаётся доступна, содержимое прокручивается внутри. Учтены клавиатура, размеры целей касания и уменьшение анимации.
- `public/navigation.js`: минимальная необходимая правка восстановления фокуса. Браузерная проверка обнаружила, что отложенное событие закрытия меню повторно переводило фокус с открытой встроенной формы на кнопку меню. Теперь фокус восстанавливается один раз; код и механизм формы не менялись.
- Футер использует тот же реестр без изменений шаблона, брендового блока, контактов, кнопок YouTube/VK Видео и их оформления.
- Обновлены ожидания существующих тестов, версия сборки и инструкция запуска. Проверка публикации в `.github/workflows/pages.yml` дополнительно проверяет новый порядок шапки, меню «3 + 2» и ресурсы навигации.

## Проверки

Команды для повторения:

```sh
PREVIEW_MODE=0 npm test
PREVIEW_MODE=0 BASE_PATH=/Website_ERA npm test
PREVIEW_MODE=0 BASE_PATH=/Website_ERA npm run build
ERA_PREVIEW_URL=http://127.0.0.1:3045/Website_ERA python3 test/navigation.browser.py
```

Браузерный сценарий не создаёт скриншотов: 320, 390, 768, 900, 1024, 1200, 1280, 1440 и 1920 px; порядок колонок, отсутствие горизонтального переполнения, цели от 44 px, Tab/Shift+Tab, Escape, закрытие кнопкой и подложкой. Отдельно проверяются активные состояния 15 маршрутов, 36 реальных переходов из меню и футера, модальная и встроенная формы без отправки, старые редиректы, 404, низкое окно 1440 × 620 и ссылки футера без JavaScript. Результат сохраняется вне сборки: `/tmp/era-navigation-0354/browser/results.json`.

Результат: 76 из 76 тестов для корня и 76 из 76 для префикса GitHub Pages; браузерный сценарий завершён успешно на всех девяти ширинах, ошибок JavaScript нет. Проверка публикации отдельно прошла на локальной сборке с префиксом.

Сравнение с 0.35.3 подтвердило сохранность 532 исходных файлов, содержимого `<main>` и `<head>` всех 32 страниц (за исключением технической версии ресурсов в URL). Стили входа в каталог также сохранены. Расчёты, исходные данные, медиа, PDF, формы, оборудование, заголовки и SEO страниц не редактировались. Брендированные каналы и три подключённых мессенджера сохранены.

Публикация выполняется штатным GitHub Actions после проверок; workflow проверяет HTTP 200 для главной, «О нас», контактов, галереи и четырнадцати ресурсов, а также отсутствие режима макета.
