## Инженерный монитор

В составе линии осталась одна интерактивная схема 01–27. Изображение 1853×1299 полностью вписывается по ширине; в обычном режиме нет внутренних полос прокрутки, захвата мыши и автоматического перемещения к позиции. Номера и выноски исходного изображения сохранены без масок и повторных линий. Нижняя консоль имеет стабильную высоту. Группа 20 содержит пять бункеров, 25 — четыре секции рольгангов, 27 — два разных погрузчика.

`interactiveLineDiagram(d,{fit:true})` включает отдельный вариант. Старые схемы мини-линии и узлов продолжают использовать прежние CSS/JS. В полноэкранном режиме доступны fit и масштаб; при отсутствии/отказе API используется доступный dialog. Esc, кнопка закрытия, ограничение фокуса и восстановление прокрутки проверяются браузерным тестом.

## Документы и загрузка

A0 зарегистрирован через `additionalDocuments`, категория `drawings`, объект `line:separatsiya-02`, optional `format:'A0'`. Проверенная обложка создана существующим `npm run documents:covers`; исходные 27 PDF и 27 обложек не изменены. В релизе 28 публичных PDF; интерфейс, фильтры и счётчики используют данные реестра.

На линии ровно две карточки из того же реестра: техническое описание на 32 страницах и A0. Брошюра остаётся в общей подборке линии. Обе карточки и планшет используют существующий singleton `pdf-viewer`; исходные ссылки/download сохраняются без JS. PDF.js загружается только при открытии. Для A0 расширен нижний предел масштаба общего viewer, чтобы лист действительно вписывался на телефоне. Модуль и дополнительные CSS подключены только на полной линии.
