# Каталог ЭРА · 0.39.4

Основа: `3ee697be21a242d7357f6e202cd7204b69ce1b4c` (0.39.3). Сохранены опубликованные изменения страниц «О нас» и «Контакты».

## Изменения

- `/catalog/`: согласованные тексты, две целые ссылки, исходные сцены 3:2 целиком, естественная высота текстов, прежняя золотая подсветка без изменения геометрии.
- `/catalog/lines/`: переходы между ветками, быстрые направления из реестра, компактные неактивные черновики, одно нативное раскрываемое сравнение 01/02.
- `/catalog/equipment/`: переходы между ветками, открытые категории из реестра, прежние поиск и фильтр сырья с пересечением условий.
- Единственный обработчик фильтров в `catalog-branches.js`, подключённый только на двух корнях. Нативные поля задают состояние; кнопки улучшают их после проверки DOM. URL читается заново при `pageshow` и `popstate`; `replaceState` сохраняет существующий `history.state` и чужие параметры.
- Без JavaScript все карточки и ссылки доступны, быстрые кнопки скрыты, поля не обещают работающую фильтрацию. При несовпадении группы быстрых кнопок остаётся рабочий видимый native select.

## Источники и сохранность

`test/fixtures/catalog-preserved.json` фиксирует снимки реестра, 12 полных карточек узлов, двух готовых карточек линий, 14 детальных страниц и SHA-256 32 исходных WebP (два размера каждой сцены, обложки и иллюстрации).

Сравнение находит линии по slug, метрики — по смысловым label и единицам, с проверкой уникальности. Порядок полей не влияет на значения. Вместимость накопителей берётся из проверенного `lineMetrics`. Сортировка у 01 остаётся дополнительной опцией; пять накопителей и автоматическое прессование относятся только к базе 02. Условия расчётного выхода при засоре около 50% и мощности 70% явно указаны.

Не изменены содержимое `content/`, `nodeCard`, `equipmentCardData`, изображения, PDF, manifest, CSS карточек узлов/готовых линий, детали изделий, общий контекстный возврат, глобальные токены, шапка и подвал. Независимая логика медиатеки в `interactions.js` сохранена побайтово.

## Проверка и публикация

Обязательные команды: `npm ci --omit=optional`, `npm test`, `BASE_PATH=/Website_ERA npm test`, `BASE_PATH=/Website_ERA npm run build`, `npm run documents:validate`.

`test/catalog.browser.py` проверяет три страницы на восьми ширинах (320–1920 px) и трёх высотах, полные сцены, реальную фильтрацию, сравнение, клавиатуру и touch, query/reset, историю, `pageshow`, `popstate`, native fallback и no-JS. Дополнительно используются существующие проверки карточек, навигации и технического архива. Снимки экрана остаются локальными материалами проверки.

Штатный Pages workflow дополнен `test/catalog-public.mjs`: проверка фактически опубликованных трёх маршрутов, версии CSS/JS, 32 WebP по SHA-256 и работы каталога в Chrome. Остальные публичные проверки сохранены.
