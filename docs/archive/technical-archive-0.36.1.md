# Компактные категории и Technical Archive — 0.36.1

Задание: [утверждённая инструкция](ERA_CODEX_DOCUMENT_NAVIGATION_TECHNICAL_ARCHIVE_v0360_2026-11-15.md). Публикация на действующем GitHub Pages после проверок, без скриншотов.

## Изменения

- Корневая `/documents/` сохраняет большой hero, пять категорий, поиск, все документы, подборки объектов и запрос документации.
- На пяти внутренних маршрутах — компактный intro, шесть настоящих ссылок-вкладок, поиск и PDF выбранной категории. Большая витрина и подборки объектов не повторяются. На мобильном дополнительные фильтры раскрываются при выборе и автоматически показывают активные условия; горизонтальная полоса открывает активную вкладку в видимой области.
- Один общий `scripts/context-navigation.mjs` добавляет липкую панель под шапкой только на пяти категориях, 12 узлах и двух включённых линиях. Прежние breadcrumbs заменены, инженерные разделы и anchor-nav сохранены.
- Родительские URL всегда работают без JavaScript. Возврат в историю разрешается лишь после подтверждённого перехода по собственной ссылке, с проверкой сайта/базового пути, referrer, времени и записи истории. Одного `history.length` или referrer недостаточно. Неизвестный или внешний вход ведёт к родителю. Если после внутренних якорей нужен fallback к тому же родителю, сохранённые фильтры включаются в родительскую ссылку.
- Лёгкий `context-history.js` подключён через существующий `interactions.js`, чтобы подтверждать переходы также из технологии, витрины или каталога. Он не добавляет интерфейс на эти страницы. CSS и обработчик самой панели подключаются только на вложенных маршрутах. Сохраняются только свои адреса и разрешённые параметры навигации; темы заявок, email и токены не записываются.
- Каталог и библиотека сохраняют `history.state` при обновлении фильтров. Смещение якорей и правого индикатора учитывает обе липкие полосы; алгоритм индикатора не перерабатывался.
- Карточки Technical Archive: стальной градиент, две тонкие направляющие вне титульной страницы, мягкая предметная тень, светлая холодная текстовая часть. Пропорции и исходные WebP сохранены; ориентация берётся из размеров обложки. Такой же стиль используется в списке.
- PDF-viewer, его модальная клавиатура, реальные скачивания и ZIP до 50 МБ сохранены. Новых npm-зависимостей нет.

## Проверки

```sh
npm ci --omit=optional
npm run documents:validate
npm test
BASE_PATH=/Website_ERA npm test
BASE_PATH=/Website_ERA npm run build
ERA_PREVIEW_URL=http://127.0.0.1:3049/Website_ERA python3 test/technical-archive.browser.py
ERA_PREVIEW_URL=http://127.0.0.1:3049/Website_ERA python3 test/documents.browser.py
```

Node-проверки включают компактную структуру, только документы нужной категории, единственный общий возврат на применимых маршрутах, приватность, отрицательные случаи истории и прежние проверки PDF/обложек/ZIP. Браузерные сценарии не создают снимков: размеры 320–1440 px и высота 720 px, реальные переходы, активная вкладка, направляющие, отсутствие горизонтального переполнения, безопасный внешний вход, возврат с фильтрами и якорями, PDF/меню/формы над панелью, вариант без JavaScript.

Регрессионный сценарий заново отображает все 27 PDF, скачивает и сверяет их SHA, проверяет ZIP и лимит 50 МБ. Контрольные суммы 27 оригиналов, 27 обложек и их реестров сверяются с 0.36.0. При сравнении страниц исключаются только предусмотренные изменения библиотечных представлений, прежних breadcrumbs и технических подключений CSS/JS.

Публикация дополнительно проверяет по HTTP компактные категории, сохранённую корневую витрину, Technical Archive, панель на узлах/линиях и 27 ресурсов интерфейса; прежние проверки оригинальных PDF и обложек остаются.

Итог проверки перед публикацией: 87/87 Node-тестов в обоих режимах, успешные браузерные сценарии Technical Archive и всей библиотеки. Отдельно проверены Ctrl-click, эквивалент 200% увеличения и корневое размещение. Все 60 защищённых файлов (PDF, обложки, их реестры и ядро просмотрщика) совпадают с 0.36.0. На 14 инженерных страницах изменена только прежняя навигационная цепочка; содержимое остальных 17 страниц и глобальные шапка/футер сохранены.
