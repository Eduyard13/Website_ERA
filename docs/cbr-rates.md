# Курсы валют Банка России

На всех страницах, включая 404, закреплена нижняя панель USD, EUR и CNY. Значения приведены в рублях за одну единицу валюты с четырьмя знаками после запятой. Панель оформлена в общей сине-золотой палитре. Место под неё зарезервировано в документе, чтобы последние ссылки и текст оставались доступны при прокрутке; меню учитывает её высоту.

## Официальный источник и даты

Источник — HTTPS XML Банка России: https://www.cbr.ru/scripts/XML_daily.asp. В запрос передаётся date_req с текущим днём по Europe/Moscow. Используется именно запрос на нужную дату: выгрузка без даты может содержать уже опубликованные курсы следующего дня.

В снимке сохраняются requestedDate (день запроса), effectiveDate (Date из XML ЦБ), fetchedAt (время получения), оригинальный URL, номинал, значение и курс за единицу. Сохранён также SHA-256 исходного XML. ЦБ может вернуть более раннюю дату действия в выходной или праздник. Панель показывает «на» день запроса и отдельно «Действуют с» фактическую дату. При старом снимке используется «данные за», без обозначения его как сегодняшнего.

Числа с десятичной запятой нормализуются, курс делится на Nominal. Отсутствующая или повторяющаяся валюта, некорректные числа, неподходящий источник и дата действия позже дня запроса отклоняются. Непроверенные значения в панель не выводятся.

## Автоматическое обновление

Workflow .github/workflows/rates.yml работает ежечасно и допускает ручной workflow_dispatch. При изменении его кода запускается проверка и обновление. Node 24 получает официальный XML с проверкой HTTPS, проверяет три валюты и публикует маленькие cbr.json и cbr.xml в отдельной ветке data/cbr-rates. Эта ветка отделяет частые обновления данных от версий исходного сайта. Для задания выдаётся contents:write, остальные задания сохраняют свои разрешения. Автоматизация использует стандартный GITHUB_TOKEN Actions.

Клиент читает публичный JSON своего репозитория:
https://raw.githubusercontent.com/Eduyard13/Website_ERA/refs/heads/data/cbr-rates/cbr.json

Обновление выполняется при открытии страницы, каждые 15 минут на открытой вкладке, при возвращении к вкладке, смене московского дня и восстановлении сети. Credentials не передаются. Ответ проходит ту же проверку схемы и дат. Значения помещаются в DOM через textContent. Последний корректный снимок хранится в localStorage.

При сетевой ошибке показываются сохранённые курсы с соответствующей подписью и датой. Если корректных данных ещё нет, видны прочерки и сообщение о недоступности; вымышленные курсы не подставляются. Если официальный запрос в Actions не выполнен, последняя успешная выгрузка в ветке данных сохраняется.

Первый запуск workflow успешно получил запрос на 01.11.2026 с датой действия 31.10.2026. Сохранённые JSON и XML сверены по контрольной сумме и значениям. Браузер получает этот реальный снимок по HTTPS с CORS публичного raw.githubusercontent.com.

## Проверки

test/cbr-rates.test.mjs проверяет десятичную запятую, Nominal, выходной, московскую полночь, недопустимые ответы и параметры официального запроса. Эти тесты включены в npm test и в workflow обновления.

test/fx.browser.py проверяет живой источник, три размера экрана, закрепление при прокрутке, доступность футера и меню, 404, 15-минутный опрос, кэш, ошибку сети, старую дату и восстановление. Синтетические ответы используются только внутри теста отказов; они не публикуются в ветке данных или на сайте.
