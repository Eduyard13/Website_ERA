# Шапка и навигация — 0.10.0

Реализовано задание владельца из ERA_Header_Navigation_Codex.md. Основная строка содержит оригинальный логотип, три прямые ссылки, кнопку «Все разделы» и обращение. Высота шапки вместе с компактной строкой валют — 86–88 CSS-пикселей. На ширине от 1000 пикселей показываются три прямые ссылки; ниже — логотип и кнопка «Меню». Подписи и контакты получаются из единых content/navigation.mjs и content/contact.mjs.

Активный раздел вычисляется при статической сборке по пути, без query и hash. Главная проверяется точным совпадением; каталог — совпадением сегмента /catalog или его потомков. Для точной ссылки используется aria-current=page, для принадлежности родительскому разделу — data-current-section и data-current-branch. Кнопка панели независимо хранит aria-expanded. Страница 404 не получает активную главную.

Панель — нативный modal dialog с правым расположением и шириной до 620 пикселей. На маленьком экране она занимает всю доступную ширину. Её положение согласовано с фактической координатой шапки; кнопка закрытия и мобильное обращение находятся вне прокручиваемой части. Повторное нажатие в области переключателя, Escape, кнопка закрытия, фон и выбор ссылки закрывают панель. Фокус замкнут с Tab/Shift+Tab; закрытие возвращает его на переключатель. Состояние сбрасывается при pageshow, включая восстановление из истории. Прокрутка фона блокируется с компенсацией реального размера полосы прокрутки, без постоянного пустого поля по краю страницы.

В /catalog/ два крупных входа: линии и комплексы, затем отдельные узлы. Числа получаются из реестра: два включённых проекта сепарации, один мойки, 12 узлов в шести категориях. Дополнительный проект сепарации остаётся в прежнем фильтре линий. Компоновка линии взята из существующей презентации; иллюстрации узлов — из уже проверенных технических материалов. Проекты не названы утверждёнными серийными комплектациями.

Старая /about/ содержала описание проекта, последовательность подбора и перечень направлений сайта. Эти сведения включены в существующий блок главной #about-era; остальные секции главной сохранены. /about/ теперь служит статической страницей перехода с meta refresh, location.replace и обычной ссылкой. На GitHub Pages это браузерный переход с ответом HTML, не HTTP 301/302. Ссылки футера и двух материалов галереи направлены на корневую главную.

test/navigation.browser.py проверяет состояния и маршруты на ширинах 360, 768, 1024 и 1440, модальный фокус, прокрутку, все способы закрытия, CTA, историю, поиск и фильтры, обе ветки каталога, старый адрес с JavaScript и без него, а также 404. Снимки главной и страницы узла, шапки и панели сохраняются в /workspace/era-review/navigation-v0.10/. Штатные тесты выполняются для корня и /Website_ERA/.

Технология, карточки, PDF, медиатека, валютный источник, способ обращения и настройки индексации сохранены. Изменения ограничены навигацией, входом в каталог и переносом сведений со старой страницы проекта.
