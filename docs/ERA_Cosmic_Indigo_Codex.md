# ERA — «Космический индиго»: настройка цвета для Codex

Статус: выбран заказчиком. Источник: интерактивный образец «Космический индиго» из пяти оттенков синего, показанных в этой переписке.

## 1. Задача

Замени прежний фирменный синий на «Космический индиго» во всём интерфейсе сайта ERA. Для крупных синих поверхностей используй точный градиент из выбранного образца с едва заметной фактурой и мягким свечением.

Это задание имеет приоритет перед прежними указаниями о синей палитре. Сохрани утверждённую структуру сайта, навигацию, содержимое и расположение элементов. Основное меню: **О проекте → Оборудование → Технология → Все разделы**. Активный раздел должен по-прежнему выделяться, в том числе «О проекте» при первом открытии главной страницы.

Меняем фирменный цвет на существующих элементах; светлые страницы и карточки сохраняют свои светлые поверхности. Золото и тёплый белый остаются прежними.

## 2. Утверждённые цвета

| Роль | Точный цвет | Применение |
| --- | --- | --- |
| Космический индиго | `#10132E` | Основной фирменный синий, текст, ссылки, кнопки, сплошные заливки |
| Свечение индиго | `#353960` | Два мягких световых поля в градиенте; наведение на сплошную синюю кнопку |
| Глубина индиго | `#050714` | Самые тёмные участки градиента |
| Золото | `#C6A43B` | Существующие золотые акценты, логотип, маркеры, акцент на тёмном фоне |
| Тёплый белый | `#F7F4EE` | Светлый фон и основной текст на индиго |

**«Космический индиго» — именно `#10132E`, а не прежний синий `#102B46`.** Свечение имеет лёгкий фиолетовый подтон; не сдвигай его в бирюзовый, электрический синий или ярко-фиолетовый. Не подбирай другие значения «на глаз».

## 3. Единые токены темы

Найди существующий файл темы и подключи эти значения через его систему переменных. Имена переменных можно согласовать с архитектурой проекта; итоговые значения и формула градиента должны совпадать с этим заданием.

```css
:root {
  /* Утверждённый вариант «Космический индиго». */
  --era-blue: #10132E;
  --era-glow: #353960;
  --era-deep: #050714;

  /* Существующая пара цветов ERA. */
  --era-white: #F7F4EE;
  --era-gold: #C6A43B;

  /* Семантические роли интерфейса на светлом фоне. */
  --era-primary: var(--era-blue);
  --era-primary-hover: var(--era-glow);
  --era-primary-foreground: var(--era-white);
  --era-text: var(--era-blue);
  --era-text-muted: rgb(16 19 46 / 72%);
  --era-link: var(--era-blue);
  --era-link-hover: var(--era-glow);
  --era-surface-soft: rgb(16 19 46 / 6%);
  --era-border: rgb(16 19 46 / 16%);
  --era-control-border: rgb(16 19 46 / 55%);

  /* Семантические роли на тёмной поверхности. */
  --era-on-dark: var(--era-white);
  --era-on-dark-muted: rgb(247 244 238 / 78%);
  --era-border-on-dark: rgb(247 244 238 / 18%);

  /* Точная формула из выбранного образца. */
  --era-blue-gradient:
    radial-gradient(
      ellipse at 87% 14%,
      var(--era-glow) 0%,
      transparent 58%
    ),
    radial-gradient(
      ellipse at 40% 110%,
      var(--era-glow) 0%,
      transparent 63%
    ),
    linear-gradient(
      132deg,
      var(--era-blue) 10%,
      var(--era-deep) 100%
    );

  /* Инициализируется один раз; основной градиент работает и без фактуры. */
  --era-indigo-grain: none;
}
```

Уже существующие семантические токены, например primary, navy, ink, accent-blue, должны ссылаться на соответствующие новые значения. Не создавай параллельную тему, которая не используется действующими компонентами.

## 4. Где применять сплошной цвет, а где градиент

| Элемент | Настройка |
| --- | --- |
| Заголовки и основной текст на белом/бежевом | Сплошной `#10132E` |
| Ссылки на светлом фоне | `#10132E`; при наведении `#353960`; сохранить понятное подчёркивание |
| Обычная основная кнопка | Фон `#10132E`, текст `#F7F4EE`; наведение `#353960` |
| Иконки, синие линии, рамки, стрелки интерфейса | Новый индиго или его семантический токен; декоративным линиям допустима указанная прозрачность |
| Выбранный фильтр, вкладка, переключатель | Индиго со светлым текстом или лёгкая заливка на базе индиго — по существующему типу компонента |
| Крупные синие блоки, первый экран, тёмные секции, подвал | Точный градиент из раздела 3 и деликатные слои из раздела 5 |
| Шапка сайта, панель большого меню, всплывающие панели | Если фон синий — применить ту же палитру. Крупная тёмная панель может использовать градиент; её текст и интерактивные элементы должны оставаться отчётливыми |
| Светлая шапка и светлое большое меню | Сохранить светлый фон; синие надписи, иконки и состояния перевести на индиго |
| Фирменные синие области редактируемого SVG-логотипа/иконок | Перекрасить в новый индиго, сохранив геометрию и золотые части |
| Синие участки на фотографиях оборудования, видео, технических изображениях | Сохранить исходные цвета материалов |

Градиент предназначен для поверхности, поэтому его не нужно накладывать на буквы, мелкие иконки, рамки или каждую небольшую кнопку. В этих местах тот же выбранный цвет передаётся сплошным `#10132E`.

Полупрозрачные токены `--era-text-muted`, `--era-surface-soft`, `--era-border`, `--era-control-border` предназначены для светлого фона. Для тёмных секций используй роли `--era-on-dark*` и `--era-border-on-dark`.

## 5. Точная поверхность из выбранного образца

Образец складывается из трёх частей: двух радиальных световых полей поверх диагонального градиента, очень слабого зерна и семи почти незаметных световых точек. Точки создают ощущение глубины; это не фотография неба и не россыпь декоративных звёзд.

Следующий CSS воспроизводит выбранную поверхность. Применяй класс к нужным крупным синим блокам или перенеси эти правила в существующие компоненты.

```css
.era-indigo-surface {
  position: relative;
  isolation: isolate;
  color: var(--era-on-dark);
  background-color: var(--era-blue);
  background-image: var(--era-blue-gradient);
}

/* Оба декоративных слоя расположены под содержимым. */
.era-indigo-surface::before,
.era-indigo-surface::after {
  content: "";
  position: absolute;
  inset: 0;
  z-index: -1;
  border-radius: inherit;
  pointer-events: none;
}

/* Такое же слабое зерно, как в показанном образце. */
.era-indigo-surface::before {
  background-image: var(--era-indigo-grain);
  background-size: 100% 100%;
  background-repeat: no-repeat;
  opacity: 0.12;
  mix-blend-mode: soft-light;
```

Если у компонента уже заняты псевдоэлементы, перенеси декор в два отдельных элемента с `aria-hidden="true"`. Сохрани порядок: фон → зерно → точки → содержимое. Не перекрывай декором фотографии и не меняй положение существующих элементов.

Класс не задаёт `overflow: hidden`: содержимое меню, выпадающие панели и контуры клавиатурного фокуса должны свободно отображаться. Если конкретному блоку нужно обрезать декор, обрезай отдельный декоративный контейнер.

### Однократная генерация зерна

Ниже тот же размер шумовой карты, начальное значение и алгоритм, которые использовались в показанном образце. Карта растягивается на всю поверхность и остаётся статичной.

```js
function initEraIndigoGrain() {
  if (typeof document === 'undefined') return;

  const canvas = document.createElement('canvas');
  canvas.width = 336;
  canvas.height = 224;

  const context = canvas.getContext('2d');
  if (!context) return;

  const noise = context.createImageData(canvas.width, canvas.height);
  let seed = 1947;

  for (let pixel = 0; pixel < noise.data.length; pixel += 4) {
    seed = (Math.imul(seed, 1664525) + 1013904223) >>> 0;
    const value = seed >>> 24;

    noise.data[pixel] = value;
    noise.data[pixel + 1] = value;
    noise.data[pixel + 2] = value;
    noise.data[pixel + 3] = 255;
  }

  context.putImageData(noise, 0, 0);
  document.documentElement.style.setProperty(
    '--era-indigo-grain',
    `url("${canvas.toDataURL('image/png')}")`
  );
}

initEraIndigoGrain();
```

Подключи инициализацию один раз в существующей клиентской точке входа. Если проект предпочитает статические ресурсы, допустимо один раз сформировать PNG по этому же алгоритму при сборке и подключить его через переменную `--era-indigo-grain`. Это тот же узор, а не новая текстура. Не генерируй шум повторно для каждой карточки и не запускай анимационный цикл.

Параметры зафиксированы: размер карты `336 × 224`, `seed = 1947`, `opacity = 0.12`, `mix-blend-mode: soft-light`; прозрачность слоя точек `0.24`. Не усиливай зерно, точки и свечение. Не добавляй мерцание, параллакс, туман, рисунки созвездий или фотографии космоса.

## 6. Навигация и состояния

Сохрани поведение из отдельного задания по навигации. Обнови цветовые роли:

- На светлом фоне текст меню — индиго; активный раздел — индиго с золотым подчёркиванием и существующим усилением начертания.
- На тёмном фоне текст меню — тёплый белый; активный раздел — золото с видимым подчёркиванием.
- При открытии большого меню активность страницы не должна теряться. Открытость меню и текущий раздел — разные состояния.
- Наведение, выбранное состояние и клавиатурный фокус должны различаться. Не убирай контуры фокуса и не меняй размеры текста при активации.
- На индиго используй читаемые светлые/золотые иконки. На светлом фоне — индиго.

Проверь обычные, hover, focus-visible, active, selected, expanded и disabled-состояния существующих компонентов. Старая синяя подсветка не должна возвращаться при наведении, загрузке, открытии модального окна или на мобильной версии.

## 7. Полнота замены

Перед изменением найди все источники фирменного синего в реальном репозитории:

- Глобальные переменные и стили, конфигурацию CSS-фреймворка, CSS-модули, inline-стили, мобильные переопределения и настройки темы.
- Цвета ссылок, заголовков, текста, кнопок, форм, фильтров, вкладок, иконок, загрузчиков, баннеров, шапки, подвала, панели меню и просмотрщика медиа.
- Значения HEX, RGB/RGBA, HSL/HSLA, `fill`, `stroke`, тени и старые градиенты. Примеры прежней палитры: `#102B46`, `#0A1F33`, `#173C60`; действительный список определяется исходниками.
- Редактируемые фирменные SVG, фавикон и `theme-color`, если в них используется прежний синий. Не меняй изображения предпросмотра автоматически, если их нужно отдельно переверстать.

Заменяй по назначению: основной цвет → `#10132E`, свечение/состояние наведения → `#353960`, глубокая часть фона → `#050714`. Прозрачные варианты пересчитай от RGB `16, 19, 46`, сохранив подходящую для роли прозрачность.

В собственных интерфейсных схемах фирменный синий также замени. В технических схемах сохраняй смысл легенд, цвета воды и различия технологических потоков. Цвета настоящего оборудования и исходные фотографии не перекрашивать. Загруженные PDF-документы не входят в эту замену интерфейса.

Работай через централизованные токены и существующие компоненты. Избегай глобального CSS-фильтра, массового `!important` и механической замены всех упоминаний слова blue: они могут затронуть данные, сторонние компоненты и технические обозначения.

## 8. Читаемость

Расчётный контраст сплошных цветов:

| Пара | Контраст |
| --- | --- |
| Тёплый белый `#F7F4EE` / основной индиго `#10132E` | 16,57 : 1 |
| Золото `#C6A43B` / основной индиго `#10132E` | 7,60 : 1 |
| Тёплый белый `#F7F4EE` / цвет свечения `#353960` | 10,04 : 1 |
| Золото `#C6A43B` / цвет свечения `#353960` | 4,60 : 1 |

Это расчёт для сплошных пар. На готовом градиенте проверь реальные места надписей с учётом фактуры, точек, прозрачностей и прочих наложений. Для обычного текста нужен контраст не ниже 4,5 : 1; для значимых границ и состояний контролов — не ниже 3 : 1.

Основной мелкий текст на индиго делай тёплым белым. Золото используй для акцентов. На светлом фоне основной текст остаётся индиго; существующий тёмный золотой для мелких подписей можно сохранить, поскольку основное золото `#C6A43B` для мелкого текста на белом не подходит.

## 9. Проверка результата

1. Главная страница, каталог линий и узлов, карточка узла, технология, документация, галерея, контакты, подвал и большое меню используют единую новую палитру.
2. Крупная тёмная поверхность воспроизводит именно два радиальных поля и диагональный градиент из этого файла: те же цвета, координаты, угол и остановки.
3. В малых элементах используется сплошной индиго, а в крупных тёмных блоках — согласованный градиент. Светлые поверхности сохранены.
4. Мелкие точки и зерно почти не замечаются при обычном просмотре. Поверхность выглядит глубокой и бархатной; анимации нет.
5. Все состояния кнопок, меню, фильтров и ссылок используют новые роли. Начальное выделение «О проекте» и выделение вложенных разделов работают как раньше.
6. Проверены ширины 320–360, 768 и 1440 px: градиент сохраняет процентные координаты, текст читается, меню и фокус не обрезаются.
7. Исходные фото, видео, документы, структура страниц и функции каталога сохранены.
8. Выполнены существующие проверки сборки проекта и краткая визуальная проверка перечисленных типов страниц. В отчёте назови изменённые файлы, применённые токены и результаты проверок; если какой-либо источник прежнего синего остался, объясни его назначение.

## 10. Готовый запрос для Codex

> Примени к существующему сайту ERA приложенное задание «Космический индиго». Заказчик утвердил основной цвет #10132E, свечение #353960 и глубокую тень #050714. Замени прежний фирменный синий во всём интерфейсе через централизованные токены, включая текст, кнопки, ссылки, иконки, меню, фильтры, состояния, тёмные секции и мобильные стили. Крупные синие поверхности должны получить точный градиент и деликатную фактуру из разделов 3 и 5. Сохрани золото #C6A43B, тёплый белый #F7F4EE, утверждённую навигацию и все функции сайта. Светлые поверхности остаются светлыми. Используй готовые CSS/JS из файла, адаптируя только подключение к стеку проекта. Выполни изменения в коде, проверь сборку и ключевые страницы, затем кратко отчитайся о результате.
