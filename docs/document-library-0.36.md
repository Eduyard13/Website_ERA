# Инженерная библиотека — 0.36.0

Задание: [утверждённая мастер-инструкция](ERA_CODEX_DOCUMENT_LIBRARY_MASTER_IMPLEMENT_DEPLOY_v0355_2026-11-15.md). Обновляется действующий GitHub Pages; скриншоты не создаются.

## Реализация

- `/documents/` и пять общих представлений `/documents/brochures/`, `/documents/technical/`, `/documents/layouts/`, `/documents/drawings/`, `/documents/investments/`.
- Начальный индекс: **27 PDF**, 13 брошюр/обзоров и 14 техописаний; документы 12 узлов и двух линий. Все 27 физических PDF зарегистрированы по одному разу.
- Полная линия 02 сохраняет старый файл `technical/era-separatsiya-01-technical-description.pdf`; мини-линия 01 — отдельный PDF с `mini` в имени. Исходные файлы, downloadName, SHA и ссылки каталога сохранены.
- Первая страница каждого оригинала преобразована в WebP до 840 px, без обрезки. 27 обложек занимают около 2 МБ. Проверяются SHA источника/обложки и размеры; PDF не пересохраняются.
- Тёмный hero, пять категорий в сетке 3 + 2, карточки/список, фильтры, поиск по названию и существующему описанию объекта, подборки и обратные ссылки. `ё/е`, дефисы, старые `product`/`kind`, `replaceState` и `popstate` поддерживаются.
- Локальный PDF.js 6.5.438: текущая страница, навигация, масштаб, подгонка по ширине, сброс, загрузка/ошибка, отдельный исходник и скачивание. Модальный фокус, Escape, стрелки, отмена рендера и освобождение worker. Модули и PDF загружаются только по действию пользователя.
- Локальный fflate 0.8.3: выбор опубликованных PDF, ZIP без пересжатия до 50 000 000 байт, счётчик объёма, отмена и отдельные ссылки при превышении/ошибке.
- Пустые категории готовы к наполнению и открывают существующую форму с темой. Неподтверждённых дат, редакций, чертежей и финансовых документов нет. Уровни `request-only` и `preparing` поддерживаются реестром и валидатором.
- Старые inline-карточки документов в каталоге остаются прежними. Новые категории используют тот же общий пункт меню, без изменения карты навигации. Для локального сервера добавлены правильные MIME `.mjs` и `.wasm`.

Пополнение: [инструкция оператора](document-library-maintenance.md). В CI добавлен `npm ci --omit=optional`; обложки коммитятся, поэтому Poppler/Pillow в CI не нужны.

## Проверка

- 82/82 Node-теста в корне и 82/82 с `/Website_ERA`; установка по lock-файлу и обе сборки.
- Браузер: 320, 390, 768, 900, 1200, 1440 и 1920 px, категории 3 + 2, все фильтры, старые URL, Back, формы без отправки, отсутствие горизонтального переполнения, варианты без JavaScript.
- Все 27 PDF реально отрендерены PDF.js; каждый скачан и сверен по SHA. После закрытия всех документов worker освобождался. В 32-страничном техописании проверены первая, вторая и последняя страницы, масштаб, клавиатура и возврат фокуса.
- ZIP распакован и сверен с оригинальными SHA; лимит сохраняет выделение и даёт отдельные ссылки. Проверены повреждённый PDF и рабочий fallback.
- Новый документ категории `layouts` проверен через изолированную запись и общую отрисовку: обложка, фильтр линии, PDF-viewer и скачивание. Тестовая запись и файлы не попадают в `public/` и финальный `dist/`.
- При сравнении с 0.35.5 сохранены тела и заголовки 31 прочей страницы. Все 27 PDF совпадают по размеру и SHA; экономика, оборудование, изображения, формы, КАИР, галерея, футер и меню не перерабатывались.
- Workflow после деплоя проверяет по HTTP библиотеку, пять категорий, 27 обложек, четыре оригинальных PDF с SHA, 23 ресурса и прежние страницы сайта. Публичный результат подтверждается в отчёте GitHub Actions перед выдачей ссылки.

Браузерные JSON-отчёты и скачанные временные материалы хранятся вне репозитория в `/tmp/era-document-library-0360/`; исходные PDF после проверок не менялись.
