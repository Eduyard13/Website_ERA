Сравнения на 390 и 1440 px сняты при первом посещении в версиях 0.48.1 и 0.48.2. Снимки `before-390.png`, `after-390.png`, `before-1440.png`, `after-1440.png` и `settings-390.png` находятся в артефакте `ERA_0.48.2_VISUAL`.

В трёх юридических HTML сохранены прежние адреса CSS и JavaScript. При тёплом кеше этих адресов полоса обновляется при ревалидации. Свежая сессия сразу показывает нижнюю полосу на всех трёх страницах.

Два известных ожидания браузерных тестов воспроизведены на 0.48.1 и 0.48.2. `catalog.browser.py` ожидает горизонтальную прокрутку мобильной таблицы, `media.browser.py` ожидает 14 карточек альбомов. Сравнительный тест подтвердил одинаковую таблицу, фильтры, 16 карточек альбомов и работу просмотра фото и видео в обеих версиях.

Подготовка, проверка и испытания проводились на локальных копиях в Linux с Chromium, Node.js 24, Python 3.12 и PHP 8.3. Установка на Рег.ру выполняется отдельно по `ERA_0482_INSTALL.md` после подтверждения владельца.
