# Художественная графика каталога ЭРА

Дата: 1 ноября 2026 года. Графика подготовлена встроенным инструментом генерации изображений с использованием выбранного эскиза и реальных исходных изображений оборудования. Окончательная геометрия художественной обложки не заменяет технический чертёж.

## Назначение файлов

- `masters/catalog-lines-exhibition.png` — окончательная тёмная сцена линии.
- `masters/catalog-nodes-museum.png` — окончательная светлая композиция трёх узлов.
- `assets/` — веб-версии тех же сцен; выполнено только кодирование WebP и создание уменьшенных разрешений, без изменения композиции.

## Исходники

- `source-equipment/line-layout.webp` — компоновка линии из действующего каталога.
- `source-equipment/preliminary-shredder.webp` — предварительный измельчитель.
- `source-equipment/ballistic-separator.webp` — баллистический сепаратор.
- `source-equipment/vertical-rotary-grinder.webp` — вертикально-роторный измельчитель.
- `references/approved-diptych.png` — выбранное владельцем направление оформления.

Для будущих изменений предпочтительно редактировать PNG-мастер с этими исходниками как опорой. Для первого внедрения новые генерации не нужны.

## Ориентир для повторной работы: линия

Полная отдельная обложка без надписей и логотипа. Портретная композиция 4:5. Цельная линия из исходника размещена в глубоком индиговом выставочном зале, с правдоподобной сталью, окрашенными деталями, мягким боковым светом и сдержанными отражениями на полу. Высокий ракурс, читаемые транспортёры, рамы, основные машины и выходная часть. Сохранять узнаваемую компоновку, не добавлять механизмы и потоки. Все важные части в кадре. Внизу — спокойный тёмный пол. Без людей, вывесок, текста, кнопок, декоративной рамки, неона и водяных знаков.

## Ориентир для повторной работы: три узла

Полная отдельная обложка без надписей и логотипа. Портретная композиция 4:5. Светлый архитектурный зал в тёплом белом/айвори. Три конкретные машины из исходников: измельчитель глубже слева, вертикально-роторный измельчитель глубже справа, баллистический сепаратор ближе к зрителю. У каждой собственная низкая матовая платформа. Разные глубины, небольшие перекрытия только краёв. Все корпуса, приводы и опоры читаются. Единый мягкий выставочный свет, реалистичные материалы и тени. Не соединять узлы трубами или транспортёрами; это три независимых экспоната. Без посторонних машин, людей, музейного декора, золотых пьедесталов, надписей и элементов интерфейса.

Текстовые ориентиры описывают замысел и не гарантируют пиксельного повторения. Готовые мастера сохраняют выбранный результат.
