# YouTube и VK Видео — оформление 0.35.3

Изменения по [заданию владельца](ERA_CODEX_YOUTUBE_VK_BRANDED_CARDS_FOOTER_v0351.md)
от 15 ноября 2026 года. База — опубликованная версия 0.35.2 (`16bf0ce`),
включая действующие MAX/WhatsApp и порядок «О нас» → «Контакты».
Публикация выполняется по прямому постоянному поручению владельца
после проверки давать ссылку на обновлённый сайт.

- Контакты: две одинаковые по габаритам светлые карточки с тонкой цветной линией,
  насыщенным SVG-знаком в небольшом бейдже, указанными в задании описаниями и
  выровненной нижней зоной действия. YouTube — красный, VK Видео — синий.
- YouTube сохраняет текущий URL и открывается всей карточкой в новой вкладке.
  VK Видео остаётся `null`, без ссылки, наведения и табуляции, со статусом
  «Канал подключается». При заполнении URL оба шаблона активируются автоматически.
- Футер: две платформенные кнопки высотой 48 px с теми же SVG, светлыми названиями,
  сдержанным оттенком фона и тонкой рамкой. В узком варианте 320 px они стоят
  друг под другом; общая сетка футера сохранена.
- Hover поднимает активную карточку на 3 px, кнопку футера на 2 px; фокус выделен
  отдельным контуром. Reduced motion отключает перемещение и переходы.
- Вектор VK использует геометрию Simple Icons (CC0-1.0) и дополнительный play-маркер.
  YouTube — залитый скруглённый play-знак. Оба SVG встроены в разметку, используют
  корректный viewBox и aria-hidden. Внешних запросов к иконкам нет.

## Файлы

- `content/contact.mjs`: только два описания видеоканалов; реальные URL не менялись.
- `scripts/contact-channels.mjs`: единый рендер карточек и футерных кнопок, SVG,
  состояние без URL и доступные подписи. Мессенджеры сохранены.
- `public/video-channels.css`: изолированные стили обеих версий компонента.
- `public/contact-premium.css`, `public/footer.css`: удалены прежние стили только
  видеоплашек; формы, карта, контакты и общий footer layout сохранены.
- `scripts/build.mjs`: подключение общего небольшого CSS.
- `.github/workflows/pages.yml`: публичная проверка также нового CSS.
- `test/about-contacts.test.mjs`: оба состояния каналов и автоматическая активация
  основного/компактного шаблонов через тестовые данные.
- `package.json`, `README.md`, эта записка и исходное задание.
