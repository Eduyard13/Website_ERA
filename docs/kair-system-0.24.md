# Система управления КАИР — 0.24.0

## Задача и размещение

Страница `/automation` объединяет материалы об управлении оборудованием. В меню и подвале остаётся один пункт «Система управления КАИР»; самостоятельного раздела ИИ больше нет. `/ai` содержит только совместимое перенаправление на `/automation`, canonical и обычную ссылку на случай отключённого JavaScript. Параметры адреса и якорь сохраняются при переходе со скриптом. Корневое размещение и `/Website_ERA` поддержаны.

Страница содержит восемь последовательных разделов:

1. Польза для производства: шесть групп задач, переход к соответствующим функциям.
2. Настоящие экраны: прежние 23 фотографии с ручным и автоматическим просмотром и fullscreen.
3. Логика действий: подача, защита измельчителя, память режимов, среда мойки. Четыре независимых состояния одной схемы.
4. Функции: поиск, фильтры «Все / Сепарация / Мойка / Автоматика узлов», раскрываемые группы, результат и сброс.
5. Связь с оборудованием: отдельные маршруты сепарации и мойки; возврат жидкости, очистка стоков и ополаскивание разделены.
6. Практические ситуации: восемь основных, ещё 16 раскрываются дополнительно. У каждой есть ситуация, действия, польза и необходимые условия.
7. Оснащение: основа Siemens, HMI, датчики конкретных узлов, видеоконтроль и условия шкафов; ссылки на узлы.
8. Подбор под проект: оборудование, функции, условия работы и проверка состава; связь с экономикой и контакты.

В основных ситуациях выбраны № 01, 03, 04, 06, 08, 13, 15 и 19 исходного перечня. Номера остальных сохранены для будущей редакции.

Сценарии обозначены как типовые; экономический результат требует фактических данных процесса.

## Задел под графику

Визуальный слой вынесен в `scripts/kair-visuals.mjs`; страница уже содержит работающие адаптивные схемы на HTML/SVG. `data-artwork-slot` задаёт устойчивые точки для дальнейшего развития. Пустых рамок и вымышленных живых показаний нет. Функции, текстовые подписи и доступное управление сохраняются при добавлении изображений.

| Блок / точка | Что изображается сейчас | Подробная графика для следующей редакции |
| --- | --- | --- |
| `kair-overview` | Состояние, параметры и режимы → КАИР → механизмы, защита, информация | Общая схема сигналов по согласованной архитектуре; широкий формат около 4:3, мобильная вертикальная версия |
| `kair-logic-coordination` | Четыре шага согласования подачи | Компоновка с направлением материала и подтверждёнными связями приводов |
| `kair-logic-protection` | Вибрация/шум → уставки → отключение привода → проверка | Выноски двух вибрационных и двух шумовых датчиков измельчителя, реальный экран реакции |
| `kair-logic-memory` | Поставщик/сырьё → выбор режима → настройки → проверка партии | Реальный экран выбора настроек и его связь с технологическими параметрами |
| `kair-logic-washing` | Состояние среды → алгоритм → дозирование → контроль | Реальный pH-контур, дозаторы и точки ввода после подтверждения состава приборов |
| `kair-process-separation` | Четыре функциональных участка, раздельное накопление | Иллюстрация расширенной линии № 02 с маршрутами выбранных фракций и микса |
| `kair-process-washing` | Буфер/ветка → среда → центрифуги/флотаторы → чистый материал | Компоновка мойки по актуальной спецификации, без смешения номеров разных ТО |
| `kair-water-circuits` | Три отдельных маршрута: возврат на предыдущие участки, очистка в основную мойку, чистая вода на ополаскивание | Технологическая схема жидкости с насосами, ёмкостями и подтверждёнными сигналами |
| `kair-scenario-NN` | Раскрываемое объяснение ситуации и действий | Короткое видео, экран или схема именно этого действия; формат около 16:9 внутри карточки |
| Существующий монитор | 23 фотографии из архива владельца | Дополнительные реальные экраны; оригиналы, подписи и fullscreen остаются в прежнем компоненте |

Большие схемы раскрываются через вкладки, подробности — через нативные `details`. На телефоне потоки строятся вертикально; на большом экране шаги читаются слева направо. Для вкладок доступны стрелки, Home и End; для функций — обычный поиск и кнопки области применения. Фильтры не меняют схемы и слайд-шоу.
