## 1. Цель и границы изменения

Сделать страницу контактов представительным завершением знакомства с международной машиностроительной компанией: прямые способы связи, аккуратная форма проекта, реальное производство BEIER и две доступные карты одной площадки, фирменные карточки видеоканалов. Принцип: сдержанная премиальность, простота для посетителя любого возраста, никаких декоративных заглушек вместо реально доступных сведений.

Меняем только `/contacts`, а также общий знак VK Видео в существующих карточках видеоканалов и футере, поскольку компонент используется совместно. Не перерабатывать другие страницы, структуру меню, документы, калькуляторы, логику каталога, сведения о команде и содержание «О нас». Адрес производства согласовать с уже утверждённым текстом «О нас» (единый источник данных допустим, без визуальной переработки той страницы). Не менять владельца/получателя заявок и не создавать вымышленные аккаунты. Не менять индексацию или домен в рамках этой задачи.

- В правой колонке: «ИНДИВИДУАЛЬНЫЙ ПОДБОР ОБОРУДОВАНИЯ»; H2 «Расскажите о вашем проекте.»; «Можно приложить фотографии, видео и документы.»

Вариант для desktop ≥1024px: общий контур, сетка примерно 40/60 или 44/56, левая поверхность — фирменный космический индиго (`era-indigo-surface` или те же дизайн-токены), правая — тёплый белый/молочный, широкая форма. Тонкая золотистая граница, радиус 8–12px, мягкая неглубокая тень, не два разрозненных гигантских блока. Внутренние отступы 32–48px desktop, 22–26px mobile, естественная высота по содержанию; не раздувать левый блок декоративными элементами. Контакты читаемы: телефон 27–34px desktop, почта 17–21px, белый текст на индиго, тёплый золотой акцент. Иконки 22–28px. Контраст и клавиатурный фокус, минимум 44px зона нажатия.

Пользоваться текущими CSS-переменными `--era-blue`, `--era-gold`, `--era-gold-dark`, `--era-cream`, `--era-border`, `--era-on-dark`, `--era-on-dark-muted`; не вводить новый несовместимый визуальный язык. Допустим тонкий архитектурный акцент (линия, мягкая подсветка), без иллюстрации ради заполнения пространства, без тяжелых градиентов/анимаций и стекломорфных нагромождений.

На 768–1023px сетка адаптируется по реальной ширине: при недостатке места контакты сверху, форма ниже. На мобильном одна колонка, телефон/email не обрезаются, иконки и подписи мессенджеров доступны, никаких горизонтальных прокруток. Поля не мельче 16px на мобильном. Не делать контактную колонку `sticky`, если она заслоняет форму/якоря.

## 4. Две карты: совпадающее физическое место, а не две произвольные отметки

### 4.1 Результат предварительной сверки и обязательный контроль перед выпуском

Адрес предприятия подтверждён. На официальной странице https://www.beierrecycling.com/contact-us/ обнаружен Google Maps iframe, который ссылается на объект `Bei'er Machinery` (а не просто центр города). Его оригинальный URL в исходнике:

```text
https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d3387.1186854646453!2d120.54503629999999!3d31.903372499999996!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x35b3de30aaecfbc9%3A0xc69270bb0704fe55!2sBei%27er+Machinery!5e0!3m2!1sen!2sus!4v1656289004886!5m2!1sen!2sus
```

- Google feature identifier `0x35b3de30aaecfbc9:0xc69270bb0704fe55` (в iframe).
- Числа `31.9033725, 120.5450363` — **центр области просмотра в embed**, не подтверждённые координаты самой метки. Не записывать автоматически как точный вход в завод.
- В стороннем агрегаторе деклараций по тому же адресу (ЕАЭС N RU Д-CN.РА04.А.88003/26, 08.06.2026) указана пара `32.047463, 120.244562`. Она значительно отличается от центра корпоративной карты; источник не первичный картографический. Не использовать эту пару для публикации и не считать расхождение простой перестановкой широты/долготы.
- В этой сессии опубликованную страницу ЭРА и содержимое Google iframe напрямую открыть не удалось (cache miss); Яндекс не выдал проверяемую карточку предприятия. Следовательно, совпадение точек пока **не подтверждено визуально**. Нельзя заявлять обратное.

- https://yandex.com/dev/maps/mapstools/ — конструктор и встраивание.

### 4.2 Поведение интерфейса

Один блок карты, переключатель «Google Maps | Яндекс Карты». Google по умолчанию (официальный источник BEIER); пользователь в любой стране/браузере может переключить вручную. Затем можно запоминать последний явно выбранный сервис в локальном хранилище только как UI-предпочтение, без идентификаторов и геолокации; при невозможности хранения — обычный Google. НЕ выбирать автоматически по Chrome/Яндекс Браузеру/IP: браузер не определяет страну и доступность карт. Не запрашивать location permissions. Не загружать два iframe одновременно. Лениво подключать выбранный официальный iframe после появления секции и/или явного выбора; предусмотреть понятную подпись о стороннем картографическом сервисе и возможность осознанного открытия, если сайт применяет consent-модель. Не передавать в карту содержимое заявки.

У переключателя нативные `<button type="button">` с `aria-pressed` либо корректные tabs/tabpanel, клавиатурная навигация, очевидный активный элемент, одинаковая геометрия, минимум 44px. Для встраиваемой карты `title` по провайдеру, `loading=lazy`, разрешённый referrerpolicy по документации (не `no-referrer`, если доменные ограничения API требуют referrer). Ссылки вне iframe «Открыть в Google Maps» / «Открыть в Яндекс Картах». Они всегда доступны при проверенной ссылке даже при проблемах с iframe. Для внешних ссылок `target=_blank rel=noopener noreferrer`; нельзя скрывать атрибуцию, логотипы, controls карты или перехватывать клавиатурой её функциональность. Не блокировать прокрутку страницы: не активировать wheel zoom до взаимодействия, если провайдер позволяет законно; не ставить перманентный прозрачный overlay. Никаких ложных сообщений «карта загружена» по одному событию `load` iframe: оно не доказывает успех и cross-origin нельзя читать произвольно.

При блокировке iframe браузером/сетью, наличии только внешней ссылки либо недоступности официальной Яндекс-карты показывать адрес, аккуратную карту/контейнер с честным состоянием и работающую внешнюю ссылку. Можно дать переход в Яндекс по проверенной точке; если точка не подтверждена, только **поиск по адресу** с явной подписью «Найти адрес в Яндекс Картах», без утверждения о точной метке. Не выдавать поисковый результат за совпавшую точку. Google при отсутствии визуальной проверки допустим как «Карта на официальном сайте BEIER» (ссылка на источник; iframe лишь если воспроизводится). Не ставить случайный маркер или картинку-имитацию. Отсутствие точной сверки не должно отменять премиальный дизайн, официальный адрес и фото; статус карт указывать в итогах отдельно. Если карта не загрузилась, форма остаётся полностью функциональной. Без JS — адрес и подтверждённые прямые ссылки видны.
